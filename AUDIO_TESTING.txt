NitLink CN115 v0.1.2 — 音频调试说明

修正开启漂移补偿后反复欠载的控制路径：
- FIFO 反馈观察相邻 250 ms 时间窗；正常包级波动跨过目标时，不把波峰当作持续积压。
- 输入设备与输出设备时钟估计仍作为前馈；时钟估计更新时扣除已由积分项学到的同向补偿，避免重复计算。
- 根据本次输出后实际可用的采样余量限制加速消耗，排除 Sinc 滤波历史、前视和分数相位。
- 接近欠载边界时立即限制修正，并同步约束积分项，避免保护结束后再次过度消耗。
- 欠载后清除正向水位修正，保留时钟估计与保护性的负向修正。
- 最终仍限制在 ±2000 ppm；普通跟踪变化率为 400 ppm/秒，欠载保护可立即降低消耗速度。

FIFO 与播放队列的用户目标均不改变，不自动加大缓冲。实际 FIFO 仍会随采集包到达而波动。
欠载帧与欠载次数仍如实累计；关闭补偿不会关闭统计。启动等待预填充的静音沿用原版统计规则。
阈值自动重载和失焦回退共享模式的规则不变；关闭补偿也关闭阈值自动重载。

验证：新增固定 3 ms FIFO / 约 3 ms 输出的包级仿真，覆盖 108 组送包周期、时钟偏差、抖动与标称采样率转换，每组 180 秒；区分启动/学习阶段与 10 秒后的稳定阶段。
另在 Windows WASAPI 替身上测试实际 FIFO、Sinc 与 FillRender 路径，以及关闭补偿后仍记录真实欠载。
模拟结果不等同于 GC553 或主板声卡实测；可保持相同设置做对照。

使用与对照测试
1. 解压整个 ZIP 到新目录，保留 DLL 和子目录。需要 Windows 10 1809+ / Windows 11、DX11 与 WebView2 Runtime；VC++ 运行库已随包携带。
2. 开启独占输出，FIFO 保持 3 ms，确认实际输出块仍是约 3 ms，再开启漂移补偿。
3. 让声音连续播放 10 秒，记录欠载帧、欠载次数、自动重载次数；保持窗口前台再运行至少 5 分钟，比较新增数量。
4. 同时记录 FIFO 平均/范围、时钟漂移估计和修正 ppm；不要仅凭累计总数判断这段测试是否新增欠载。
5. 关闭漂移补偿后再做同样对照，切换时会重建播放流，应重新留出启动/学习时间。
6. 若仍欠载，请附上上述数值、有无可闻断音、BUILD.txt 提交号，以及是否发生失焦/设备切换。

独占模式自动选用驱动支持的最小周期；设置面板属于同一前台窗口。失焦、最小化或隐藏时切回共享模式；回到前台稳定 200 ms 后恢复独占。切换会短暂重建音频流。
欠载按输出采样帧计，丢弃按输入采样帧计。Sinc 连续补偿看修正 ppm，不会增加“丢弃帧”。
实际 FIFO/输出块显示不是端到端实测延迟，不含全部 USB、驱动、采集卡与 DAC 延迟。
自动恢复：2 秒内欠载 3 次或累计缺失 20 ms，或水位偏差至少 max(20 ms, 两个输出块) 持续 250 ms，重建两端；冷却 10 秒。重建会短暂中断音频。
