# 香港任天堂商店通用圖片來源

來源順序為使用者手動選圖／本機加工圖、香港任天堂商店、Nintendo Taiwan 精選素材、SteamGridDB。
香港來源由商店的正常公開商品搜尋與分類分頁取得，不依賴遊戲白名單或 SteamGridDB ID 對應表。
不下載整站，不執行網站腳本，不登入，也不嘗試通過機器驗證。

## 審核操作

開啟 `http://127.0.0.1:8765/nitlink-menu.html?preview=games`，使用 Real API 模式。
選擇目前遊戲後，在「選擇封面」選「香港任天堂商店」。可用任意官方商品名稱搜尋，
或清空輸入框按搜尋來瀏覽整個數位商品目錄。分頁會取得真正不同的下一批資料。
目前商店回報 1,561 個數位商品，包括不同版本、組合及追加內容，並非 1,561 款不重複遊戲。
這個數字由網站回應取得，沒有寫死在前端或 EXE。

「所有來源」會以目前遊戲的原始本地化名稱查找精確匹配的香港商品，再列出台灣精選素材與社群圖。
自訂遊戲名稱不會當成商品名稱送出。使用者可以修正官方搜尋詞，不需要前端更新遊戲清單。
同名版本及商店的寬鬆搜尋可能出現其他商品，所以通用商品候選須由使用者確認選取；
不會自動把某個重製版或追加內容的圖片套到原作。商品名稱、日期、平台（商店有標示時）保留在卡片及資訊視窗。
手動選取保持優先；收藏切換不會偷偷換圖。

目前已實際檢查《曠野之息》、瑪利歐賽車、星之卡比、Minecraft，以及空白查詢的前兩頁。
《時之笛》在香港商店目前沒有查詢結果；台灣精選素材另外提供官方歷史頁的原版 N64 美術圖。
不會拿官方現行商品目錄中的同名 Switch 2 版本冒充原版。

## 圖片與語言

只使用商店 HTML 中實際發布的圖片網址，不移除圖片快取路徑來猜測原圖網址。
已確認《曠野之息》的商店圖片預覽為 272×153；封面編輯器仍可輸出真正的 512×512 PNG。
不宣稱低解析度來源變成高解析度原圖。圖片在驗證下載、MIME、解碼及尺寸前不能選取。

商店語系、商品中文名稱、遊戲支援語言，均不等於圖片中文字語言。
通用商品圖預設語言未知，不自動加「官方繁中」角標；既有經驗證素材保留語言標示。
《時之笛》新增兩張為無文字官方美術圖，並非繁中盒裝。

## 程式與安全

- `scripts/nintendo_hk_store.py`：預覽的通用 HTML 解析、固定來源、分頁及短期快取。
- `src/app/game_service.cpp`：對應的原生 WinHTTP 背景請求／解析；重用圖片驗證、快取與本機資源交付。
- `settings_message.cpp`：僅接受來源列舉、商品名稱與分頁，不接受 URL。
- `game_identity.h`：新增僅限 `https://store.nintendo.com.hk/media/catalog/product/` 的圖片路徑。
- `preview_game_bridge.py`：以真實商店資料服務正式 HTML／JS，保留 Fixture 的離線預設。
- `menu.js`／三語資源：來源切換、任意商品搜尋、形狀篩選、來源資訊及還原。

HTTP 只讀 GET；商品頁面 12 秒／2 MiB，圖片 8 秒／8 MiB；不接受重新導向、Cookie、
任意主機、連接埠、查詢字串圖片、路徑穿越或非圖片內容。WebView2 CSP 沒有放寬。
每頁依商店的 24 筆分頁載入，快取最多 64 個查詢頁面，30 分鐘到期。

收藏保存既有封面 URL、provider、sourceLabel、isOfficial、language、region、kind 與裁切檔案。
原生 Config 接受新的 `nintendo-hk-store` 來源，其他遊戲 ID／畫質設定不變。
重新搜尋的建議縮圖不會覆蓋已保存的手動／加工圖片。
